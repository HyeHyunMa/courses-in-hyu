Basic principles of R syntax (applied in the Sources tab)

  • Pressing ENTER moves the cursor to the next line, it does not command the code to run.

  • To run a line of code, use CTRL+ENTER, CMD+ENTER, or press the RUN button.

  • Inserting # prevents the code from running.

Apply Family: lapply, sapply, tapply

  • apply란? 행렬, 배열 데이터 구조에서 특정 함수를 반복 적용하게 해주는 함수. for loops & while loops에 비해 빠르고 간편.

  • apply함수의 기본 로직: apply(X, MARGIN, FUN, ..., simplify=T/F)

    • X = 입력 데이터. 주로 데이터프레임, 행렬 or 배열

    • MARGIN = 함수가 적용될 데이터의 차원 (MARGIN=1이면 row 기준, MARGIN=2면 column 기준)

    • FUN = 적용하고 싶은 특정 함수 (ex. mean, sum, …)

    • … = FUN에 따른 추가 옵션. 예를 들어 FUN이 mean일 때 결측치를 제거하는 옵션인 na.rm=TRUE를 뒤에 작성할 수 있음.

    • simplify = 디폴트값은 TRUE, 가능한 경우 결과를 벡터/행렬로 반환. FALSE로 설정하면 결과를 리스트로 반환. (= 즉, 단순화하고 싶은 경우 simplify=T이며, 이는 sapply와 동일한 결과를 반환함)
